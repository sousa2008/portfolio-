## Ideia criativa: portfólio como molde

O portfólio também funciona como um molde vivo para demonstrar inovação e manipulação de elementos visuais: qualquer visitante pode simular o próprio site preenchendo uma cópia com as suas informações. A simulação fica salva apenas no navegador do visitante (aviso de modo demonstração) e nunca altera a versão publicada do autor — o que evita qualquer impressão de falha de segurança, pois o conteúdo original permanece intacto para todos os demais visitantes.

## Como executar

O projeto não necessita de instalação de dependências.

Para executar:

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` em um navegador atual.

Também é possível utilizar uma extensão como o **Live Server** no VS Code para executar o projeto localmente.
